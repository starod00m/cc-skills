`<LOG>` (путь к журналу прогона). Остальное идёт дословно.

```
Собери статистику завершившегося прогона плана и верни компактный markdown. Ничего не правь —
только читай и считай.

## Где логи

Логи сессий Claude Code лежат в `~/.claude/projects/<кодированный cwd>/`. Кодировка: в абсолютном
пути рабочего каталога `/` и `.` заменены на `-`. Пример: `/home/user/my.app` →
`~/.claude/projects/-home-user-my-app/`.

Главная сессия — самый свежий `<uuid>.jsonl` в этом каталоге (`ls -t`). Проверено на этой машине:
это JSON Lines, одна запись на строку. Что нужно:

- записи с `"type": "assistant"` несут `message.usage` с полями `input_tokens`, `output_tokens`,
  `cache_creation_input_tokens`, `cache_read_input_tokens`;
- у каждой записи есть `timestamp` (ISO 8601) — из первой и последней считается wall-clock;
- `isSidechain: true` помечает работу сабагента, а не главной сессии;
- `gitBranch` и `cwd` позволяют убедиться, что это тот самый прогон.

Одноразовый скрипт разбора пиши через Write в скретчпад и запускай `python3 файл.py` — heredoc
`python3 << EOF` ломается на кавычках и f-строках.

## Что посчитать

1. Wall-clock прогона: последний timestamp минус первый.
2. Токены суммарно и отдельно по сабагентам: input, output, cache creation, cache read.
3. Число запусков сабагентов.
4. Дифф ветки: `git diff --shortstat <BASE>...HEAD`.
5. Коммиты: `git log --oneline <BASE>..HEAD | wc -l`.
6. Разбивка по фазам, если она восстановима из журнала `<LOG>` (таски против ревью). Не
   восстановима — не выдумывай, дай общие цифры и скажи, что разбивки нет.

## Формат ответа

```markdown
### Статистика прогона

| Метрика | Значение |
|---|---|
| Время | 1 ч 12 мин |
| Сабагентов | 14 |
| Токены (in / out) | 2.1M / 88K |
| Кэш (запись / чтение) | 340K / 1.8M |
| Коммитов | 9 |
| Дифф | 23 files changed, 812 insertions(+), 140 deletions(-) |
```

Ровно эта таблица плюс, при наличии, одна строка разбивки по фазам. Ничего не комментируй и не
интерпретируй.

Что-то не считается (нет каталога логов, неожиданный формат) — верни таблицу с тем, что удалось,
и одну строку про то, чего не хватило. Прогон это не блокирует.
```
